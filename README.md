# Customer Churn Prediction using SVM and KNN

## Project Overview
This project predicts customer churn using Machine Learning algorithms:
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Steps Performed
1. Data Loading
2. Data Preprocessing
3. Feature Encoding
4. Feature Scaling
5. Train-Test Split
6. SVM Model Training
7. KNN Model Training
8. Elbow Method
9. Model Evaluation
10. Model Comparison

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Conclusion
The project compares SVM and KNN models to identify the best-performing classifier for customer churn prediction.
